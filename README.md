# Sales Data Cleaning and Analytics Dashboard 📊📈

A Python-based Sales Analytics Dashboard project for cleaning, processing, analyzing, and visualizing sales datasets using Excel files and data visualization techniques.

---

# 📁 Project Structure

Sales-Data-Cleaning-and-Analytics-Dashboard/
│
├── dashboard.py                      ← Main dashboard visualization script
├── datast.py                         ← Data cleaning and preprocessing script
├── sales_data_sample.xlsx            ← Raw sales dataset
├── final_structured_data.xlsx        ← Structured dataset after preprocessing
├── cleaned_sales_data.xlsx           ← Final cleaned dataset
│
├── graphs/
│   ├── sales_chart.png               ← Sales visualization chart
│   └── missing_values_heatmap.png    ← Missing values heatmap
│
└── README.md                         ← Project documentation

---

# 📦 Dataset Information

The project uses Excel-based sales datasets containing sales transaction details.

### Files Used

| File Name | Description |
|---|---|
| sales_data_sample.xlsx | Raw input sales dataset |
| final_structured_data.xlsx | Structured processed dataset |
| cleaned_sales_data.xlsx | Cleaned final dataset |

# 🚀 How to Run the Project

## Step 1 — Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

---

## Step 2 — Open Project Folder

Open the extracted project folder in:

- VS Code
- PyCharm
- Jupyter Notebook
- Command Prompt

---

## Step 3 — Run Data Cleaning Script

```bash
python datast.py
```

This script:
- Cleans the dataset
- Handles missing values
- Structures the sales data

---

## Step 4 — Run Dashboard Script

```bash
python dashboard.py
```

This script generates:
- Sales charts
- Data analytics visualizations
- Dashboard outputs
